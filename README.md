# Marketplace Revenue Leakage & Gap Analysis

## About the Project

This is one of the projects I completed during my Business & Marketing Analytics training.

In this project, I used SQL to study marketplace data and understand how different costs such as discounts, returns, logistics charges and payment fees can reduce profit.

The main purpose of the project was to practice working with multiple tables and use SQL to answer business-related questions.

## What I Wanted to Find

I wanted to understand:

- How much sales the marketplace generated
- How much profit was available before other costs
- Which factors were reducing profit
- How discounts affected profitability
- How returns and logistics costs affected the business
- Which payment methods had higher processing fees

## Data Used

The project used six related datasets:

- Orders
- Products
- Discounts
- Returns
- Logistics
- Payment Fees

The cleaned orders data contained **17,441 records**.

## Tools Used

- SQL
- MySQL
- Excel for reviewing and checking data

## What I Did

During the project, I worked on:

- Understanding the different tables
- Connecting related tables using SQL joins
- Calculating sales and profit
- Comparing discounted and non-discounted orders
- Checking return-related losses
- Studying logistics costs
- Comparing payment processing fees
- Summarizing the main findings

## What I Found

Some of the main findings from the project were:

- Total sales were approximately **₹4.98 Crore**
- Basic profit before leakage was approximately **₹2.68 Crore**
- Total measured revenue leakage was approximately **₹91.11 Lakh**
- Estimated net profit after these leakage factors was approximately **₹1.76 Crore**

The major leakage areas were:

| Area | Approximate Amount |
|---|---:|
| Discounts | ₹45.83 Lakh |
| Returns | ₹27.66 Lakh |
| Logistics | ₹9.40 Lakh |
| Payment Fees | ₹8.21 Lakh |

Discounts were the largest leakage area in the analysis, followed by returns.

I also found that discounted orders had lower average profit compared with non-discounted orders.
